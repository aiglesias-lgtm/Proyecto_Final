Nombre del Proyecto	: GitEasy 

Tipo de Proyecto: Micro-herramienta de ayuda de github
Lenguaje de Programación: 	Python 
Entorno de Desarrollo: Visual Studio Code
Arquitectura de Código: 1 Módulo Principal  4 Módulos de Operación
Librerías Nativas: subprocess, pathlib, osy

Objetivo General: Desarrollar un programa modular en Python que automatice las operaciones frecuentes de Git y proporcione soporte técnico inmediato ante errores comunes de consola.

Problema que resuelve: Reduce la barrera de entrada para estudiantes y principiantes que desconocen la sintaxis de comandos como git init, git merge o git push.
